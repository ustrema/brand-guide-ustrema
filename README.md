# Ustrema — Brand Guide

Interactive brand guide for **Ustrema** (Устрема), a Microsoft Power Platform and governance consultancy based in Sofia.

**View it:** https://ustrema.github.io/brand-guide-ustrema/

- Switch colour schemes, preferred logo marks and type pairings from the sidebar; the whole guide re-themes.
- Shareable states via URL parameters, e.g. `?pal=M&logo=m01`.
- `assets/logo/` — draft marks, lockups and app icons. `assets/tokens.css` / `tokens.json` — design tokens.

Status: **draft for discussion**. Marks and colours are not final.
